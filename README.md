# Data Structures and Algorithms (DSA) Practice Hub

A structured, centralized repository for tracking my algorithmic problem-solving journey, covering materials from LeetCode, HackerRank, and various tutorials. 

## 📂 Repository Structure

The repository is organized by problem-solving paradigms and data structures:

- **Data Structures**
  - Arrays & Strings
  - Linked Lists
  - Stacks & Queues
  - Hash Tables & Maps
  - Trees & Binary Search Trees (BST)
  - Graphs (BFS, DFS, Shortest Path, etc.)
  - Heaps & Priority Queues
  - Tries

- **Algorithms & Techniques**
  - Two Pointers & Sliding Window
  - Binary Search
  - Recursion & Backtracking
  - Dynamic Programming (DP)
  - Greedy Algorithms
  - Bit Manipulation
  - Sorting & Searching

- **Platforms & Sources**
  - `leetcode/`: Solutions categorized by problem number/difficulty.
  - `hackerrank/`: Practice problem implementations.
  - `tutorials/`: Notes and code snippets from core concepts and learning resources.

## 🚀 Goals
- Write optimized code focusing on optimal **Time** and **Space complexity**.
- Document alternative approaches (Brute Force $\rightarrow$ Better $\rightarrow$ Optimal).
- Maintain consistent daily practice.
